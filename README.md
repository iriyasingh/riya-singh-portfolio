## ⚡ Portfolio Features

This portfolio is crafted in **Constructivist Art & Neo-Industrial Design** featuring:

- 🚩 **Constructivist Design System**: Crimson Red (`#D92626`), Obsidian Black (`#0D0D0D`), Vintage Cream (`#F4F1DE`), and Cyan (`#00F0FF`) colorways with heavy structural borders, diagonal ribbons, marquee tickers, and hard offset shadows.

- 🔐 **Developer Mindset & Defensive Security Pipeline**: 6-stage interactive engineering flow (`PROBLEM` ➔ `ANALYZE` ➔ `DESIGN` ➔ `CODE` ➔ `SECURE IT 🔐` ➔ `DEPLOY 🚀`) with OWASP threat modeling checklists.
- 🛠️ **Tech Matrix**: Filterable skills matrix covering Programming Languages, MERN Web Development, Cybersecurity & Systems, and AI / Emerging Technologies.
- 📱 **Full Mobile & All-Screen Responsiveness**: Fluid typography (`clamp()`), mobile slide-out navigation drawer, and touch-friendly layouts built with **TypeScript**.

## 🚀 Quick Start Guide

### 1. Clone or Download Repository
```bash
git clone https://github.com/iriyasingh/riya-singh-portfolio.git
cd riya-singh-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Local Development Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** in your browser.

### 4. Build Production Bundle
```bash
npm run build
```

## 🌐 Deployment & Domain Configuration

This portfolio is configured for deployment on **Vercel** with custom `.is-a.dev` domains.

### Vercel Deployment
1. Import the repository into your Vercel account.
2. The `vercel.json` file is already included to configure routing and headers.
3. Deploy the project. Vercel will automatically build using `npm run build` and output to the `dist` directory.

### Custom Domains (`.is-a.dev`)
The following domains are linked to the Vercel project:
- `riyasingh.is-a.dev`

- `iriyasingh.is-a.dev`

- `riya.is-a.dev`

**To manage or verify domains:**
- The domain DNS records (A Records pointing to Vercel's IP `216.198.79.1` and `_vercel` TXT verification records) have been submitted to the [is-a-dev/register](https://github.com/is-a-dev/register) repository.
- Once merged by the maintainers, Vercel will automatically verify the domains and issue SSL certificates.
